# voila-basic-ui

This app shows how a simple user interface can be built to simulate and interact with simulation results using the libraries:

- [Plotly](https://plotly.com/python/)
- [Jupyter Widgets](https://ipywidgets.readthedocs.io/en/stable/)
- [Modelon Impact Client](https://modelon-impact-client.readthedocs.io/en/latest/)
